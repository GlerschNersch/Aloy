Minerva connects Aloy to the physical environment:

* **Smart Home**: 20+ configured lights, perimeter smart locks, and climate thermostats via Home Assistant.
* **Ambient Room Observer**: Real-time vision analysis via Logitech C930e webcam.
* **Health & Biometrics**: Heart rate, sleep score, and activity telemetry via Amazfit smartwatch.
