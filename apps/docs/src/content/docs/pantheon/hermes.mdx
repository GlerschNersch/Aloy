Hermes is Aloy's dialectic reflection engine. Rather than treating conversation history as a static linear log, Hermes builds a continuous conceptual graph of user preferences, cognitive patterns, and active life goals.

## Key Capabilities

* **Dialectic Evolution**: Identifies contradictions, shifts in goals, and emergent projects across conversations.
* **Semantic Anchor Mapping**: Builds high-density episodic anchors stored in `data/hermes_graph.json`.
* **Proactive Context Injection**: Injects relevant context into the system prompt before the primary model generates a reply.
