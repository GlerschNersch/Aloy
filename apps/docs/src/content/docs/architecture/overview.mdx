## Distributed Topology

```mermaid
flowchart TD
    subgraph Clients["Clients Layer"]
        Desktop["💻 Aloy Desktop (Electron + React 19)"]

    subgraph Core["Aloy Core Nervous System (Port 7890)"]

        Security["🛡️ Security Guard (Realpath Sandbox & Bearer Auth)"]
    end

    subgraph Pantheon["⚡ The Pantheon Engines"]
        Hermes["📜 Hermes (Dialectic Memory)"]
        Heph["🔨 Hephaestus (Autonomous Dev)"]
        Athena["🦉 Athena (Research Synthesis)"]
        Apollo["🧠 Apollo (Episodic Recall)"]
        Minerva["👁️ Minerva (Smart Home & Vision)"]
    end

    subgraph Targets["Physical World & Remote Rigs"]
        HA["🏠 Home Assistant (REST & WebSocket)"]
        Roku["📺 Living Room Roku Ultra (Port 8060 ECP)"]
        Bazzite["🎮 Bazzite Gaming Station (SSH)"]
        Lenny["🖥️ Lenny Media Server (SSH)"]
    end

    Desktop --> Server
    Mobile --> Server
    Server --> Router
    Server --> Security
    Server --> Pantheon
    Pantheon --> Targets
```

:::tip[Architectural Rule]
The Aloy Mobile app is a thin client that connects directly to `aloyServer.cjs` over Tailscale/LAN. Chat threads, memory vaults, and tool executions are strictly owned by the primary server.
:::
