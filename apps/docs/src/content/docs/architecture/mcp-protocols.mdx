---
title: Model Context Protocol (MCP) Integration
description: Standardized sidecar and tool integration via MCP servers.
---

Aloy natively supports Model Context Protocol (MCP) clients and servers over standard stdio:

* **Filesystem MCP**: Safe directory sandbox for notes and media.
* **Git MCP**: Automated repository analysis, diff generation, and commit management.
* **Fetch MCP**: Web content extraction and documentation scraper.
