The Universal Media Dispatcher coordinates playback across 10+ smart displays and compute machines on your local network.

## Supported Playback Targets

* **Living Room Roku Ultra (4850X)**: Native ECP deep-linking via HTTP POST `/launch/592369?contentId=...&mediaType=movie`.
* **Bedroom Roku Ultra (4660X)**: Roku Media Player App channel ID `2213`.
* **Bazzite Gaming Station**: Remote MPV playback launch via SSH.
* **Lenny Media Server**: Direct Jellyfin session synchronization.
* **This PC (Workstation)**: Local desktop video player.
* **Party Mode (Broadcast Everywhere)**: Multi-room synchronized audio/video streaming.
